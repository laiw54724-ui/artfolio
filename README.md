# Artfolio — 繪師的作品集小窩 🖤🤍

一個給繪師/創作者的極簡黑白作品集網站模板。作品散落在各大平台?把它們全部 collect 回自己家!

- **零程式基礎可用**:內建視覺化編輯器,填表單就能更新網站
- **資料在自己手上**:整個網站就是你 GitHub repo 裡的檔案,隨時整包帶走
- **完全免費**:部署在 Cloudflare Pages,免費方案流量無上限
- **功能**:自我介紹+平台連結、作品集(分類篩選+搜尋+燈箱+R-18 遮罩)、時間軸、留言板(含管理頁)、黑白雙主題切換
- **外觀自訂**:主題預設包一鍵套用、Logo/favicon、背景圖、5 種字體、自訂配色+強調色、圓角、欄數、灰階開關——即時預覽
- **繪師營運**:委託狀態徽章、公告置頂欄、圖片自動壓縮+批次匯入+浮水印
- **保護與擴散**:AI 爬蟲阻擋、防右鍵開關、社群分享卡(OG)、RSS 訂閱
- **完整響應式**:手機、平板、電腦都好看

## 檔案結構

```
├── index.html            ← 網站本體(不用改它!)
├── editor.html           ← 內容編輯器(在瀏覽器打開來用)
├── admin.html            ← 留言板管理頁(站長用)
├── data.json             ← 你的所有內容都在這裡
├── images/               ← 你的作品圖片放這裡
├── robots.txt            ← 阻擋 AI 訓練爬蟲的名單
├── functions/
│   ├── _middleware.js    ← 社群分享卡自動注入(部署後自動生效)
│   ├── rss.xml.js        ← RSS 訂閱(部署後生效於 /rss.xml)
│   └── api/guestbook.js  ← 留言板 API(部署後自動生效)
├── schema.sql            ← 留言板資料庫建表指令
└── LICENSE               ← MIT 授權(記得把名字改成你的)
```

## 部署教學(跟著做一次約 15 分鐘)

### 第 1 步:把模板變成你的

1. 註冊/登入 [GitHub](https://github.com)
2. 建立一個新 repository(例如叫 `my-portfolio`),把這包檔案全部上傳
   (網頁上傳即可:repo 頁面 → Add file → Upload files → 整包拖進去)

### 第 2 步:部署到 Cloudflare Pages

1. 註冊/登入 [Cloudflare](https://dash.cloudflare.com)
2. 左側選 **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. 授權 GitHub、選你剛建立的 repo
4. Build 設定**全部留空**(這個模板不需要建置),直接按 **Save and Deploy**
5. 等一分鐘,你會拿到一個 `xxx.pages.dev` 網址——網站上線了!🎉

### 第 3 步:開通留言板(D1 資料庫)

1. Cloudflare 左側選 **Storage & Databases** → **D1** → **Create database**,取名(例如 `guestbook`)
2. 進入資料庫 → **Console** 分頁 → 把 `schema.sql` 的內容整段貼上執行
3. 回到你的 Pages 專案 → **Settings** → **Bindings** → **Add** → 選 **D1 database**
   - Variable name 填:`DB`(一定要是這個名字!)
   - 選剛剛建立的資料庫
4. (推薦!留言管理頁要用)Settings → **Variables and Secrets** → 新增 **Secret**:
   - 名稱 `ADMIN_TOKEN`,值填一串你自己發明的長密碼(之後在 admin.html 輸入它來管理留言)
5. 到 **Deployments** 分頁按 **Retry deployment** 重新部署一次,讓綁定生效
6. 打開你的網站,留言板可以用了!

### 第 4 步:換成你自己的內容

1. 打開你網站的 `你的網址/editor.html`(或直接在電腦上雙擊 editor.html)
2. 填寫你的名字、介紹、連結,新增作品和時間軸
3. 按右上角 **匯出 data.json**
4. 回到 GitHub repo → 點 `data.json` → 鉛筆圖示或 Upload 用新檔蓋掉 → Commit
5. 新的作品圖片也上傳到 `images/` 資料夾(GitHub 網頁就能傳)
6. Cloudflare 幾十秒後自動更新網站,完成!

> 💡 圖片建議:單張 1–2MB 以內、寬度 1200–1600px 就很夠了,網站會跑得比較快。

## 外觀自訂

打開 editor.html → 「外觀自訂」區。全部都是選填,什麼都不動就是經典黑白。

| 項目 | 說明 |
|---|---|
| Logo / Favicon | Logo 顯示在左上角標題旁(透明背景 PNG、高度 ≥96px);favicon 是瀏覽器分頁小圖示(正方形 ≥192px,填頭像也行) |
| 字體 | 標題與內文分開選:明體、黑體、文楷(手寫感)、圓體、舊明朝 |
| 配色 | 勾選後只要挑「背景+文字」兩色(亮暗主題各一組),整站顏色自動衍生;另可加一個強調色(按鈕、選中分類、時間軸圓點) |
| 版面 | 圓角 0–20px、作品 2 或 3 欄、作品是否轉黑白(**彩圖繪師記得關掉!**) |
| 背景圖 | 滿版:1920×1080 以上、壓到 500KB 內。平鋪:200–512px 正方形無縫圖樣、100KB 內。用「淡化程度」調到 5–15% 最不搶戲 |

改完按編輯器右上角「👁 預覽」,會開新分頁直接看效果(不用先匯出);
滿意了再「匯出 data.json」蓋回專案。

## 繪師營運功能

**委託狀態徽章**:編輯器 →「營運小工具」→ 選狀態(🟢 開放/🟡 排滿/⚪ 暫停),
會顯示在首頁名字下方,可以連到你的委託價目表。

**公告置頂欄**:一行公告顯示在網站最上方(「新刊通販中!」),可加連結,訪客可以關掉。

**R-18/敏感內容**:每件作品可個別勾選 🔞,勾了之後縮圖會霧化+顯示「點擊顯示」,
點一下才會揭開。同一瀏覽分頁內確認過的作品不會重複詢問。

**作品搜尋**:作品區右上角的搜尋框,標題/標籤/說明/分類都搜得到。

**圖片自動壓縮**(超重要!):直接丟原圖會把網站拖垮。
在編輯器的作品卡按「選圖」,它會在你的瀏覽器裡自動把圖壓成最長邊 1600px 的 JPG
並下載給你,路徑也自動填好——你只要把下載的檔案放進 images/。
「批次匯入」更狠:一次選 30 張圖,自動壓縮打包成 zip + 自動建立 30 張作品卡,搬家神器。

**浮水印**:在「圖片工具」開啟後,之後壓縮的圖都會自動在右下角加上你的署名。

**留言板管理**:打開 `你的網址/admin.html`,輸入你設定的 ADMIN_TOKEN,
就能一鍵隱藏/恢復任何留言,不用碰資料庫。

## 作品保護

**AI 爬蟲阻擋**:`robots.txt` 已內建封鎖名單(GPTBot、CCBot、Bytespider 等 16 種)。
但 robots.txt 是君子協定,建議再到 Cloudflare 後台開啟強制封鎖:
你的網域 → **Security** → **Bots** → 開啟 **Block AI Bots**(免費方案就有,一個開關搞定)。

**防右鍵/防拖曳**:編輯器 →「網站設定」勾選即可。老實說只能防君子(截圖擋不了),
真正有效的是浮水印+不要上傳原尺寸大圖(壓縮工具順便就幫你做到了)。

## 分享與訂閱

**社群分享卡**:部署後,把網址貼到 X/Discord/LINE 會自動顯示「網站標題+介紹+頭像」的預覽卡,
資料來自 data.json,不用設定。

**RSS**:部署後 `你的網址/rss.xml` 自動生效,粉絲用 RSS 閱讀器訂閱,
你新增作品他們就收到——不用受演算法擺佈,把這個網址放在你的社群簡介吧。

## 日常更新流程

畫了新圖 → 圖片丟進 GitHub 的 `images/` → 打開 editor.html 新增作品 → 匯出 data.json 蓋回去 → 完成。

## 備份/搬家

你的整個網站 = 這個 repo。`data.json` + `images/` 就是全部資料,
複製一份就是備份,搬去任何靜態網站服務都能直接用(留言板部分限 Cloudflare)。
留言資料在 D1:Dashboard → D1 → 你的資料庫 → Console 執行
`SELECT * FROM comments` 就能看到全部;想匯出可用
`npx wrangler d1 export 資料庫名稱 --remote --output=backup.sql`。

## 模板升級

以後這個模板出新版時,你只要**換掉程式檔**(index.html、editor.html、admin.html、functions/),
**千萬不要動** data.json 和 images/——你的所有內容都在那兩個地方,換完程式檔內容原封不動。

## 常見問題

**Q:留言板顯示「尚未啟用」?**
A:檢查第 3 步——D1 有沒有建、綁定名稱是不是 `DB`、綁定後有沒有重新部署。

**Q:想改配色/字體?**
A:內容都不用碰 `index.html`,但如果你懂一點 CSS,檔案開頭 `:root` 區塊的變數就是全部顏色,想從黑白改成別的色系只要改那裡。

**Q:可以用自己的網域嗎?**
A:可以!Pages 專案 → Custom domains → 照指示加上你的網域(在 Cloudflare 買網域最省事)。
